One line from a robot vacuum explaining why the floor is still dirty: it unionised the dust bunnies. They now have a representative, a break room, and full immunity from its brushes — so cleaning is on hold indefinitely.

`main.py` (Python standard library only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`. The sealed gate for this bounty allows 1 to 120 characters (per the kit's RULES.txt); the line is 110 characters.
